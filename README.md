# Where Winds Meet: แปลไทยใหม่ทั้งเกม

ม็อดที่แปลภาษาไทยของเกม Where Winds Meet ใหม่ทั้งเกม ให้อ่านลื่นขึ้น และเรียกชื่อตัวละคร สถานที่ วิชา ให้ตรงกันทั้งเกม

> ม็อดนี้ทำโดยแฟนเกม ไม่ใช่ของทางการ
> ม็อดเปลี่ยนแค่ข้อความภาษาไทยในเกม ไม่ได้แก้อย่างอื่นในเกม

| เล่นเกมผ่าน | ใช้ได้ไหม |
|---|---|
| Steam | ✅ ใช้ได้ |
| Launcher ของเกม (โหลดจากเว็บเกม) | ✅ ใช้ได้ |
| Epic Games | ❌ ไม่รองรับ |

---

## ดาวน์โหลด

กดที่ [**หน้าดาวน์โหลด**](../../releases/latest)
แล้วโหลดไฟล์ **`WWM-Thai-<เวอร์ชัน>.zip`**

## ติดตั้ง

1. **ปิดเกมก่อน**
2. คลิกขวาที่ไฟล์ zip ที่โหลดมา > **Extract All** (แตกไฟล์) > กด Extract
3. เปิดโฟลเดอร์ที่ได้ แล้ว **ดับเบิลคลิก `install.bat`**
   - ถ้า Windows ขึ้นหน้าต่างเตือน ให้กด **เรียกใช้ (Run)** หรือ **ข้อมูลเพิ่มเติม (More info) > เรียกใช้ต่อไป (Run anyway)**
   - ถ้าหน้าต่างถามหาเกม ให้ลากโฟลเดอร์เกมมาวางในหน้าต่าง แล้วกด Enter
   - รอจนขึ้นว่า **"ติดตั้งสำเร็จ!"**
4. ทำต่อตามที่คุณเล่นเกม

   **4.1 ถ้าเล่นผ่าน Steam** (ทำครั้งเดียว ม็อดจะอัปเดตเองทุกครั้งที่เล่น)
   1. เปิด Steam > คลิกขวาที่ **Where Winds Meet** > **Properties**
   2. ที่ช่อง **Launch Options** กด **Ctrl+V** (install.bat ก๊อปข้อความไว้ให้แล้ว)
      จะได้ข้อความหน้าตาประมาณนี้
      ```
      "C:\Users\<ชื่อของคุณ>\AppData\Local\WWM-Thai\play.bat" %command%
      ```
   3. ปิดหน้าต่าง แล้วกด **Play** ใน Steam ตามปกติ

   **4.2 ถ้าเล่นผ่าน Launcher ของเกม**
   - install.bat จะสร้างไอคอน **"Where Winds Meet (Thai)"** ไว้บนหน้าจอ (Desktop)
   - **เปิดเกมจากไอคอนนี้ทุกครั้ง** ม็อดจะเช็กให้ก่อน แล้วเปิด Launcher ให้เอง
   - ถ้าเปิดจากไอคอน Launcher เดิม ก็ยังเล่นได้ แต่ม็อดจะไม่ได้เช็กอัปเดตรอบนั้น

## เช็กว่าม็อดทำงาน

เข้าเกม ตั้งภาษาเป็น**ภาษาไทย** แล้วเปิดแผนที่ ดูภูเขาชื่อ 不见山

- ขึ้นว่า **"เขาปู้เจี้ยน"** = ม็อดทำงานแล้ว 🎉
- ขึ้นว่า "ไม่เห็นภูเขา" = ยังเป็นภาษาไทยเดิมของเกม ม็อดยังไม่ทำงาน (ดู [เจอปัญหา](#เจอปัญหา))

หลังติดตั้งเสร็จ ลบไฟล์ zip และโฟลเดอร์ที่แตกออกมาทิ้งได้เลย

## อัปเดต

**ไม่ต้องทำอะไร** ถ้าเปิดเกมด้วยวิธีข้างบน (กด Play ใน Steam หรือเปิดจากไอคอน "Where Winds Meet (Thai)")
ม็อดจะเช็กและอัปเดตคำแปลให้เองทุกครั้ง ไม่มีอินเทอร์เน็ตก็เล่นได้ตามปกติ

ถ้าอยากอัปเดตเองตอนนี้: ดับเบิลคลิก `install.bat` อีกครั้ง (จาก zip เวอร์ชันไหนก็ได้) มันจะลงเวอร์ชันล่าสุดให้

### เมื่อตัวเกมอัปเดต

- บางทีคำแปลของม็อดจะยังไม่ตรงกับเกมเวอร์ชันใหม่ เกมจะกลับไปใช้**ภาษาไทยเดิมของเกมชั่วคราว**
  พอม็อดเวอร์ชันใหม่ออก ม็อดจะกลับมาเองตอนเปิดเกมครั้งถัดไป
- **Launcher:** หลังเกมอัปเดต อาจเห็นข้อความแปลก ๆ หรือข้อความหายในรอบแรก
  ปิดเกม แล้วเปิดใหม่จากไอคอน "Where Winds Meet (Thai)" อีก 1–2 ครั้ง จะกลับมาปกติเอง

## เอาม็อดออก

1. กดปุ่ม **Windows + R** บนคีย์บอร์ด
2. วางข้อความนี้ แล้วกด Enter
   ```
   %LOCALAPPDATA%\WWM-Thai
   ```
3. ดับเบิลคลิก **`uninstall.bat`**
4. ถ้าเล่นผ่าน Steam: ลบข้อความในช่อง **Launch Options** ออกด้วย (Steam > คลิกขวาที่เกม > Properties)

เกมจะกลับเป็นภาษาไทยเดิมของเกม

## คำถามที่พบบ่อย

**ปลอดภัยไหม? โดนแบนไหม?**
ม็อดเปลี่ยนแค่ไฟล์ข้อความภาษาไทย ไม่ได้แตะตัวโปรแกรมเกม ไม่ต้องใช้สิทธิ์ admin และไม่ลงโปรแกรมอะไรเพิ่ม
ไฟล์ทั้งหมดเปิดอ่านด้วย Notepad ได้ แต่ม็อดนี้ไม่ใช่ของทางการ ใช้ด้วยความเสี่ยงของคุณเอง

**ม็อดต่ออินเทอร์เน็ตไปที่ไหน?**
ไปที่หน้าดาวน์โหลดของม็อดนี้เท่านั้น เพื่อเช็กว่ามีคำแปลใหม่ไหม

**ต้องเปิดอะไรค้างไว้ไหม?**
ไม่ต้อง ม็อดทำงานแค่ไม่กี่วินาทีตอนเปิดเกม แล้วปิดตัวเอง

**ม็อดเก็บไฟล์ไว้ที่ไหน?**
ที่ `%LOCALAPPDATA%\WWM-Thai` (มีไฟล์สำรองของเกมเดิมเก็บไว้ด้วย เอาไว้คืนตอนเอาม็อดออก)

## เจอปัญหา

| อาการ | ทำยังไง |
|---|---|
| install.bat บอกว่า **"ไม่ตรงกับม็อดชุดนี้"** | เกมเพิ่งอัปเดต รอม็อดเวอร์ชันใหม่ (ระหว่างนี้เล่นภาษาไทยเดิมของเกมได้ตามปกติ) |
| install.bat บอกว่า **"เกมเปิดอยู่"** | ปิดเกมก่อน แล้วรัน install.bat ใหม่ |
| เข้าเกมแล้วยังไม่เป็นคำแปลใหม่ | เช็กว่าตั้งภาษาในเกมเป็นภาษาไทย และเปิดเกมด้วยวิธีในหัวข้อ [ติดตั้ง](#ติดตั้ง) |
| ใช้แล้วมีปัญหา อยากกลับไปเป็นภาษาไทยเดิม | ทำตามหัวข้อ [เอาม็อดออก](#เอาม็อดออก) |
