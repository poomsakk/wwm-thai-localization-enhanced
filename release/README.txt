ม็อดแปลไทย Where Winds Meet
============================

แปลภาษาไทยใหม่ทั้งเกมจากต้นฉบับภาษาจีน (ม็อดแฟนเมด ไม่ใช่ของทางการ)

รองรับ: Steam / Epic Games / ตัวติดตั้งของเกมเอง (launcher.exe)
มี 2 วิธีให้เลือก
  ก. ติดตั้งด้วย install.bat (แนะนำ) - เช็กเวอร์ชันเกม สำรองไฟล์ และอัปเดตม็อดให้เอง
  ข. ติดตั้งด้วยมือ - ก๊อปไฟล์เอง ไม่รันสคริปต์ใด ๆ แต่ต้องดูแลเองทุกอย่าง


==================================================================
ก. ติดตั้งด้วย install.bat (แนะนำ)
==================================================================

ขั้นที่ 1 (ทุกแพลตฟอร์ม)
------------------------
1. แตกไฟล์ zip ก่อน (คลิกขวา > Extract All)
   ** อย่ารันจากในหน้าต่าง zip ตรง ๆ **
2. ปิดเกม
3. ดับเบิลคลิก install.bat
   - ถ้า Windows ถามว่า "ไม่สามารถยืนยันผู้เผยแพร่ได้" ให้กด เรียกใช้ (Run)
   - สคริปต์จะหาเกมให้เอง ถ้าเจอหลายที่จะให้เลือกหมายเลข
   - ถ้าหาไม่เจอ ให้ลากโฟลเดอร์เกม (หรือไฟล์ wwm.exe / launcher.exe) มาวางในหน้าต่าง แล้วกด Enter
4. ทำขั้นที่ 2 ตามแพลตฟอร์มของคุณด้านล่าง
5. เข้าเกม แล้วตั้งภาษาเป็น ไทย

หลังติดตั้งแล้ว ลบโฟลเดอร์ที่แตกจาก zip ทิ้งได้
(ตัวม็อดถูกเก็บไว้ที่ %LOCALAPPDATA%\WWM-Thai)


ขั้นที่ 2: Steam
----------------
install.bat ก๊อปบรรทัดคำสั่งไว้ใน clipboard ให้แล้ว
1. Steam > คลิกขวาที่ Where Winds Meet > Properties > General
2. ช่อง Launch Options กด Ctrl+V (จะได้บรรทัดประมาณ
   "C:\Users\<ชื่อคุณ>\AppData\Local\WWM-Thai\play.bat" %command% )
3. กด Play ใน Steam ตามปกติ

ถอนการติดตั้ง: ดับเบิลคลิก %LOCALAPPDATA%\WWM-Thai\uninstall.bat
              แล้วลบบรรทัดในช่อง Launch Options ออก


ขั้นที่ 2: Epic Games
---------------------
Epic ไม่มีช่อง Launch Options install.bat จึงสร้าง shortcut ให้
1. เปิดเกมจาก shortcut "Where Winds Meet (Thai)" บน Desktop
   (มันจะเช็ก/ซ่อมคำแปลก่อน แล้วสั่ง Epic Games Launcher เปิดเกมให้)
2. ถ้าเปิดจาก Epic ตรง ๆ ก็เล่นได้ แต่รอบนั้นม็อดจะไม่ได้เช็กอัปเดต
   และถ้า Epic เพิ่งอัปเดตเกม จะเป็นภาษาไทยเดิมจนกว่าจะเปิดผ่าน shortcut

ถอนการติดตั้ง: ดับเบิลคลิก %LOCALAPPDATA%\WWM-Thai\uninstall.bat
              (shortcut บน Desktop ถูกลบให้เอง)


ขั้นที่ 2: ตัวติดตั้งของเกมเอง (launcher.exe / wwm_standard / wwm_lite)
----------------------------------------------------------------------
เหมือน Epic: install.bat สร้าง shortcut ให้
1. เปิดเกมจาก shortcut "Where Winds Meet (Thai)" บน Desktop
   (มันจะเช็ก/ซ่อมคำแปลก่อน แล้วเปิด launcher.exe ของเกมให้)
2. ถ้าเปิดจาก launcher.exe ตรง ๆ ก็เล่นได้ แต่รอบนั้นม็อดจะไม่ได้เช็กอัปเดต

หมายเหตุ: แบบนี้ยังมีคนทดสอบกับเกมจริงน้อย ถ้า install.bat บอกว่า
"ไม่ตรงกับม็อดชุดนี้" หรือเข้าเกมแล้วไม่เป็นคำแปลใหม่ ช่วยส่งไฟล์
%LOCALAPPDATA%\WWM-Thai\log.txt มาให้ผู้ทำม็อดดูด้วย

ถอนการติดตั้ง: ดับเบิลคลิก %LOCALAPPDATA%\WWM-Thai\uninstall.bat
              (shortcut บน Desktop ถูกลบให้เอง)


อัปเดตอัตโนมัติทำอะไรบ้าง
------------------------
ทุกครั้งที่เปิดเกมผ่าน Steam (Launch Options) หรือ shortcut ม็อดจะ
  - เช็ก GitHub ว่ามีม็อดเวอร์ชันใหม่ไหม ถ้ามีจะโหลดและติดตั้งให้เอง
  - ติดตั้งคำแปลกลับให้เอง ถ้าตัวอัปเดตเกมเขียนทับไฟล์
ถ้าเกมอัปเดตแล้วม็อดเวอร์ชันที่ตรงกันยังไม่ออก เกมจะใช้ภาษาไทยเดิมไปก่อน
(ไม่มีทางทำให้ข้อความในเกมเพี้ยน เพราะม็อดเช็กไฟล์เกม (SHA256) ก่อนทุกครั้ง)
ไม่มีอินเทอร์เน็ตก็เล่นได้ปกติ แค่ข้ามการเช็กอัปเดตไป


==================================================================
ข. ติดตั้งด้วยมือ (ไม่รันสคริปต์)
==================================================================

สำหรับคนที่ไม่อยากรันสคริปต์ ไฟล์ที่ต้องใช้อยู่ในโฟลเดอร์ data ของ zip
แต่ไม่มีการเช็กเวอร์ชัน ไม่มีสำรองไฟล์ และไม่มีอัปเดตอัตโนมัติให้

1. เช็กเวอร์ชันเกมก่อน (สำคัญที่สุด)
   - เปิด data\manifest.txt ดูบรรทัด game_build=  (เช่น 2026-11-02/r64785)
   - เปิด <โฟลเดอร์เกม>\Engine\Binaries\Win64r\Built.version
     (ตัวติดตั้งของเกม: <...>\wwm_standard\Engine\Binaries\Win64r\Built.version)
   - ถ้าไม่ตรงกัน ** ห้ามก๊อป ** ไฟล์ม็อดที่ไม่ตรงกับเวอร์ชันเกมทำให้ข้อความในเกมเพี้ยน
     ให้รอม็อดเวอร์ชันใหม่แทน
   - (ละเอียดกว่า) เปิด Command Prompt แล้วพิมพ์
       certutil -hashfile "<ไฟล์ในเกม>" SHA256
     ผลต้องตรงกับบรรทัด orig_translate_words_map_th... ใน manifest.txt

2. ปิดเกม

3. ไปที่โฟลเดอร์ไฟล์ภาษาของเกม
   Steam      : <คลังเกม Steam>\steamapps\common\Where Winds Meet\Package\HD\oversea\locale
                (หาโฟลเดอร์เกม: Steam > คลิกขวาที่เกม > Manage > Browse local files)
   Epic Games : <โฟลเดอร์ที่ติดตั้งเกม>\Package\HD\oversea\locale
                (หาโฟลเดอร์เกม: Epic > Library > ... ที่เกม > Manage > ไอคอนโฟลเดอร์)
   ตัวติดตั้งของเกม : <...>\wwm\wwm_standard\LocalData\Patch\HD\oversea\locale
                (หรือ wwm_lite แทน wwm_standard)

4. สำรองไฟล์ 2 ไฟล์นี้ไปเก็บไว้ที่อื่น
     translate_words_map_th
     translate_words_map_th_diff

5. ก๊อปไฟล์ 2 ไฟล์ชื่อเดียวกันจาก data ของ zip ไปวางทับ

6. เข้าเกม แล้วตั้งภาษาเป็น ไทย

เมื่อเกมอัปเดต: ตัวอัปเดตเกมจะเขียนทับไฟล์ กลับเป็นภาษาไทยเดิม
  ให้รอม็อดเวอร์ชันใหม่ แล้วทำข้อ 1-6 ใหม่ (อย่าก๊อปไฟล์ม็อดเก่าทับเกมใหม่)

ถอนการติดตั้ง: ก๊อปไฟล์ที่สำรองไว้กลับไปวาง หรือใช้ปุ่มซ่อมไฟล์เกม
  Steam : คลิกขวาที่เกม > Properties > Installed Files > Verify integrity of game files
  Epic  : Library > ... ที่เกม > Manage > Verify
  ตัวติดตั้งของเกม : ปุ่มตรวจสอบ/ซ่อมไฟล์ใน launcher


==================================================================
ม็อดนี้ทำอะไรกับเครื่องคุณบ้าง
==================================================================
- แก้ไฟล์ในเกมแค่ 2 ไฟล์ (translate_words_map_th และ translate_words_map_th_diff) ใน
    Package\HD\oversea\locale             (Steam / Epic)
    LocalData\Patch\HD\oversea\locale     (ตัวติดตั้งของเกม)
  install.bat สำรองต้นฉบับไว้ที่ %LOCALAPPDATA%\WWM-Thai\backup ก่อนเสมอ
- Epic / ตัวติดตั้งของเกม: สร้าง shortcut "Where Winds Meet (Thai)" บน Desktop
- ไม่ต้องใช้สิทธิ์ admin ไม่ลงโปรแกรมใด ๆ
- ต่ออินเทอร์เน็ตเฉพาะตอนเช็กอัปเดต ไปที่ GitHub ของโปรเจกต์นี้เท่านั้น
  และตรวจ SHA256 ทุกไฟล์ก่อนใช้ อัปเดตจะแทนที่เฉพาะไฟล์ภาษา ไม่แทนที่สคริปต์
- สคริปต์ทั้งหมด (install.bat, play.bat, uninstall.bat, wwm-thai.ps1)
  เป็นไฟล์ข้อความธรรมดา เปิดอ่านด้วย Notepad ได้ทุกบรรทัด
- บันทึกการทำงานอยู่ที่ %LOCALAPPDATA%\WWM-Thai\log.txt


คำเตือน
-------
ม็อดนี้ไม่ใช่ของ NetEase/ผู้พัฒนาเกม ใช้ด้วยความเสี่ยงของคุณเอง
ม็อดแก้แค่ไฟล์ภาษา ไม่แตะไฟล์โปรแกรมหรือข้อมูลอื่นของเกม
