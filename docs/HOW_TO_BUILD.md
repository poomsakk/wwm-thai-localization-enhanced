# วิธีแปลต่อและบิวด์ม็อดเอง

หลักการ: **ใช้ AI แค่ตอนแปล** ส่วนการนำเข้า บิวด์ และติดตั้ง ทำเองด้วยไฟล์ .bat ไม่ใช้ AI เลย

## ขั้นที่ 1: เช็กว่าเหลือก้อนไหนให้แปล
ดับเบิลคลิก `build_mod.bat` บรรทัดท้ายสุดจะบอกจำนวนก้อนที่รอแปล และก้อนถัดไป เช่น
```
waiting for translation: 258  (next: 0006, 0007, 0008, 0009, 0010)
```
ไฟล์ต้นฉบับของแต่ละก้อนอยู่ที่ `work\queue\NNNN.tsv` (ก้อนใหม่ก้อนละ 30 ข้อความ; ก้อนเก่าที่แปลแล้วมี 300–400)

## ขั้นที่ 2: ให้ Claude แปล (ส่วนเดียวที่ใช้ token)
พิมพ์บอก Claude เช่น
> แปลก้อน 0006 ถึง 0008 ตาม docs/AGENT_TRANSLATION_GUIDE.md เขียนผลเป็น .out.tsv อย่างเดียว ไม่ต้องบิวด์

- ประหยัด token: สั่งครั้งละ 1–3 ก้อน และให้ Claude แปลเองในแชท ไม่ต้องใช้ agent หลายตัว
- เร็วกว่าแต่ใช้ token เร็วกว่า: สั่งให้ใช้ agent คู่ขนาน 2–3 ตัว
- ผลจะอยู่ที่ `work\queue\NNNN.out.tsv`

## ขั้นที่ 3: บิวด์และติดตั้ง (ทำเอง ไม่ใช้ AI)
1. **ปิดเกม**
2. ดับเบิลคลิก `build_mod.bat` ใช้เวลาประมาณ 15 วินาที โดยจะ
   - นำเข้าทุกก้อนที่แปลเสร็จ และตรวจอัตโนมัติ (โค้ดสี ตัวแปร ตัวจีนที่หลงเหลือ)
   - สร้างไฟล์เกมใหม่จากไฟล์ทางการที่สำรองไว้ แล้วรวมคำแปลทั้งหมดเข้าไป
   - ติดตั้งลงเกมให้
3. เปิดเกมดูได้เลย

ถ้าการตรวจอัตโนมัติขึ้นว่า `needs_fix` ข้อความนั้นจะไม่ถูกใส่ลงเกม ให้ส่งเลข id ไปให้ Claude แก้

## สลับดูของเดิมกับของใหม่
- `switch_thai.bat` สลับในเกมระหว่าง [1] MOD กับ [2] ORIGINAL (ปิดเกมก่อน)
- `compare_old_vs_new.csv` เปิดใน Excel เพื่อเทียบไทยเดิมกับไทยใหม่ทีละบรรทัด

## เมื่อเกมอัปเดต (ไม่ใช้ AI)
1. **ปิดเกม** แล้วดับเบิลคลิก `update_game.bat`
   - ตรวจว่าไฟล์ภาษาในเกมเปลี่ยนไปหรือไม่ ถ้าไม่เปลี่ยนจะบอกว่าไม่ต้องทำอะไร
   - แสดงรายงานก่อนว่าจะเปลี่ยนอะไรบ้าง เช่น key ใหม่ ข้อความใหม่ที่ต้องแปลแยกตามหมวด แล้วถามว่าจะทำต่อไหม (Y/N)
   - ถ้าตอบ Y จะสำรองไฟล์ทางการชุดใหม่ไว้ที่ `backup\original` และย้ายชุดเก่าไปไว้ที่ `backup\original_<เวอร์ชันเก่า>_replaced_<วันที่>`
   - สำรองฐานข้อมูลเป็น `work\wwm.db.bak_<วันที่>` แล้วอัปเดตฐานข้อมูลโดย**ไม่ลบคำแปลเดิม**
     - ข้อความจีนที่เคยแปลแล้ว ใช้คำแปลเดิมต่ออัตโนมัติ
     - ข้อความจีนใหม่ได้สถานะ `todo`
     - ข้อความที่เกมเลิกใช้และยังไม่ได้แปล ได้สถานะ `unused` และจะไม่ถูกนำไปตัดเป็นก้อน
2. รัน `build_mod.bat` เพื่อติดตั้ง mod บนเกมเวอร์ชันใหม่
   - `build_mod.bat` ตรวจก่อนทุกครั้ง ถ้าเกมอัปเดตแล้วแต่ยังไม่ได้รัน `update_game.bat` จะหยุดและไม่ติดตั้งไฟล์เก่าทับ
3. ข้อความใหม่ตัดเป็นก้อนได้ตามปกติ เช่น `python -I tools\translate.py chunks --category ui_short` แล้วส่งให้ batch หรือ Claude แปล
4. ตรวจว่าไฟล์ไหนติดตั้งอยู่ด้วย `python -I tools\check_installed.py` ผลจะเป็น MOD, ORIGINAL หรือ OTHER

หมายเหตุ: ตั้งแต่อัปเดตเดือน 11/2026 เกมแยกข้อความไทยเป็นสองไฟล์ คือ `translate_words_map_th` และ `translate_words_map_th_diff` ใน Package `build_mod.bat` จึง patch และติดตั้งทั้งสองไฟล์

## ไฟล์สำคัญ
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `build_mod.bat` | นำเข้า + บิวด์ + ติดตั้ง |
| `switch_thai.bat` | สลับ MOD / ORIGINAL |
| `restore_original.bat` | คืนไฟล์ทางการทั้งหมด |
| `work\queue\` | ก้อนงานแปล (`NNNN.tsv` = ต้นฉบับ, `NNNN.out.tsv` = คำแปล) |
| `backup\original\` | ไฟล์ทางการที่สำรองไว้ ห้ามลบ |
| `docs\STYLE_GUIDE.md`, `glossary\glossary.tsv` | กฎการแปลและคำศัพท์ แก้ได้ตามต้องการ |
