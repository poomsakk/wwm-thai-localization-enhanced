# Style Guide — WWM Thai Localization Enhance

> ฉบับร่าง v0.1 (2026-11-12) — ใช้เป็นคู่มือให้ทั้งคนแปลและ AI แปล

## 1. แหล่งต้นฉบับ
- **ต้นฉบับหลัก = จีนตัวย่อ (zh_cn)** ตีความความหมายจากจีนเสมอ
- **อังกฤษ = ตัวช่วย** ใช้เมื่อจีนกำกวม หรือเพื่อเช็กบริบท ห้ามแปลจากอังกฤษเป็นหลัก (อังกฤษตัดทอน/ดัดแปลงบ่อย)
- **ไทยเดิม = อ้างอิง** บรรทัดที่ดีอยู่แล้วเก็บไว้ได้ ถ้าตรงกับ Glossary และสไตล์นี้

## 2. การถอดชื่อเฉพาะ
- ใช้**สำเนียงจีนกลาง** เช่น 天泉 = เทียนเฉวียน, 开封 = ไคเฟิง, 赵州 = จ้าวโจว
- ชื่อเฉพาะทุกตัวต้องมาจาก **Glossary** เท่านั้น ห้ามถอดเองใหม่ทุกครั้ง
- ชื่อที่มีความหมายชัด (ชื่อวิชา, ไอเทม, ฉายา) ให้**แปลความหมาย**แทนการถอดเสียง เว้นแต่ Glossary กำหนดไว้
- **ชื่อสำนัก/องค์กร/สถานที่ = ถอดเสียงชื่อ + แปลคำบอกประเภท** (ตัดสินใจ 2026-11-12)
  - 门 → สำนัก, 楼/馆/阁 → หอ, 帮 → พรรค, 宫 → ตำหนัก, 寺 → วัด, 观 → อาราม, 山 → เขา, 谷 → หุบเขา, 河/江 → แม่น้ำ, 城 → เมือง
  - ตัวอย่าง: 九流门 → สำนักจิ่วหลิว, 绣金楼 → หอซิ่วจิน, 文津馆 → หอเหวินจิน, 不见山 → เขาปู้เจี้ยน
  - ถ้าชื่อไม่มีคำบอกประเภท ให้ถอดเสียงอย่างเดียว เช่น 醉花阴 → จุ้ยฮวาอิน, 天泉 → เทียนเฉวียน
- ชื่อเมือง/แคว้นที่เป็นชื่อเฉพาะอยู่แล้ว ถอดเสียงทั้งคำ เช่น 杭州 → หางโจว (ไม่แปล 州)

## 3. น้ำเสียงบทพูด — แบบ B "กำลังภายในอ่านง่าย"
- สรรพนามแบบหนังจีน: **ข้า / เจ้า / ท่าน / พวกเจ้า**
- โครงประโยคเป็น**ภาษาไทยปัจจุบัน** อ่านลื่น
- **หลีกเลี่ยงคำโบราณเกินจำเป็น**: มิได้, อันใด, ครา, ยิ่งนัก (ใช้ได้นาน ๆ ครั้งเพื่อเน้นอารมณ์)
- **ห้ามใช้** ฉัน / คุณ / เธอ / ผม / ครับ / ค่ะ ในบทพูดตัวละคร (ยกเว้นเนื้อหาที่ตั้งใจให้เป็นสมัยใหม่ เช่น ระบบ/อีเวนต์นอกเนื้อเรื่อง)

### คำเรียกตัวเองตามต้นฉบับจีน (คงลักษณะตัวละคร)
| จีน | ใช้ในไทย | หมายเหตุ |
|---|---|---|
| 我 | ข้า | ทั่วไป |
| 在下 | ผู้น้อย / ข้า | สุภาพ ถ่อมตัว |
| 老夫 | ข้าผู้เฒ่า / ตาแก่อย่างข้า | ชายสูงวัย |
| 小的 / 小人 | ข้าน้อย | ชาวบ้าน ลูกน้อง พูดกับผู้สูงกว่า |
| 本座 / 本官 / 本王 | ข้า (+ ให้ประโยคแสดงอำนาจ) | ผู้มีตำแหน่ง |
| 贫僧 | อาตมา | พระ |
| 贫道 | ข้าผู้ถือพรต | นักพรต |

### คำเรียกผู้เล่น/ผู้อื่น
| จีน | ใช้ในไทย |
|---|---|
| 少侠 | ท่านจอมยุทธ์ |
| 姑娘 | แม่นาง |
| 大人 | ใต้เท้า / ท่าน |
| 师父 | ท่านอาจารย์ / อาจารย์ |
| 师兄 / 师姐 / 师弟 / 师妹 | ศิษย์พี่ / ศิษย์พี่หญิง / ศิษย์น้อง / ศิษย์น้องหญิง |

## 4. UI / ปุ่ม / ระบบ
- **สั้น กระชับ ภาษาปัจจุบัน** ไม่ใช้สรรพนามกำลังภายใน
- ปุ่มใช้คำกริยาสั้น: ยืนยัน, ยกเลิก, รับภารกิจ, ส่งภารกิจ
- ห้ามยาวกว่าต้นฉบับจนล้นกรอบ (กฎตรวจอัตโนมัติจะเช็กความยาว)

## 4.1 ศัพท์เกม (ระบบ / การต่อสู้) — ใช้คำทับศัพท์อังกฤษ
- ศัพท์ระบบ/การต่อสู้ที่เกมเมอร์ไทยคุ้นเคย หรือแปลเป็นไทยแล้วแปลก → **ทับศัพท์อังกฤษ** (ตัดสินใจ 2026-11-13)
  - เช่น สกิล, ดาเมจ, คริติคอล, บัฟ/ดีบัฟ, ชิลด์, สตามินา, คูลดาวน์, สตัน, ไซเลนซ์, น็อกอัป, บล็อก, แพรี่, คอมโบ, บอส, ดันเจี้ยน, ซีซั่น, เลเวล, เซ็ต, กิลด์
  - ค่าสถานะใช้อักษรอังกฤษได้เมื่อเป็นตัวย่อสากล: HP, EXP
- **ใช้ภาษาอังกฤษตรง ๆ (อักษรละติน) ได้** เมื่อ (ก) เป็นชื่อเฉพาะของระบบที่แปลยาก หรือ (ข) ทับศัพท์เป็นอักษรไทยแล้วยาว/อ่านยาก (ตัดสินใจ 2026-11-13)
  - ใช้ชื่ออังกฤษทางการของเกม เช่น สายวิชาอาวุธ 4 สาย: **Bellstrike, Stonesplit, Bamboocut, Silkbind**; Super Armor, Battle Pass, Elite, Co-op, Campaign
  - คำที่เกมเมอร์ไทยเขียนเป็นอักษรไทยจนชิน ยังใช้อักษรไทย: สกิล, ดาเมจ, บัฟ, คูลดาวน์, บอส ฯลฯ
  - **เว้นวรรคหน้าและหลังคำอังกฤษ** ที่อยู่กลางประโยคไทย เช่น "โจมตี Bellstrike สูงสุด"
- ใช้**ตัวสะกดแบบที่เกมเมอร์ไทยใช้จริง** (สกิล ไม่ใช่ สกิลล์, ดาเมจ ไม่ใช่ แดเมจ) ตามที่ Glossary กำหนด
- ศัพท์ทับศัพท์ใช้**เฉพาะบริบทระบบ/การต่อสู้/UI/คำอธิบายสกิลและไอเทม** — ในบทพูดและเนื้อเรื่องให้ใช้ภาษาไทยตามบริบท (伤害 → บาดเจ็บ/ทำร้าย, 沉默 → เงียบ, 首领 → หัวหน้า)
- ศัพท์กำลังภายในที่เป็นเอกลักษณ์ยังใช้ไทย: ลมปราณ, วิทยายุทธ์, เคล็ดวิชา, พลังภายใน, ท่าไม้ตาย

## 5. กฎทางเทคนิค (ห้ามละเมิด)
- ห้ามแก้/ลบ/ย้ายลำดับโค้ดพิเศษ: `#Y…#E` (สี), `{0}` `{1}`, `%s` `%d`, `\n`, `|` (ตัวแบ่งชาย|หญิง)
- รูปแบบ `ชาย|หญิง` ต้องแปลทั้งสองฝั่ง เช่น `小兄弟|小姑娘` → `พ่อหนุ่ม|แม่นาง`
- ใช้วงเล็บจีน `【】` `「」` ตามต้นฉบับได้ หรือแปลงตามที่ Glossary กำหนด
- ห้ามมีอักษรจีนหลงเหลือในผลลัพธ์ (ยกเว้นตั้งใจ)
- ไม่ใส่จุด `.` ท้ายประโยคภาษาไทย
