# แปลด้วย Claude API

สคริปต์ `tools\claude_translate.py` ส่งก้อนงานใน `work\queue\` ไปให้ Claude แปลผ่าน API แล้วเขียนผลเป็น `NNNN.out.tsv`
ใช้กฎชุดเดียวกับที่ใช้มาตลอด คือ Style Guide, คู่มือแปล และรายชื่อชุด/ไอเทมที่ล็อกไว้ จากนั้นใช้ `build_mod.bat` นำเข้าเหมือนเดิม

- ใช้ API key ซึ่ง**คิดเงินแยกจาก subscription** (จ่ายตามจำนวนที่ใช้) จึงไม่กินโควตาแชตของคุณ
- โมเดลเริ่มต้น: **Claude Opus 5.5** ($4 / $20 ต่อล้าน token ขาเข้า / ขาออก)
- โหมด **Batch** ลดราคา 50% แลกกับการรอผล (ส่วนใหญ่ไม่เกิน 1 ชั่วโมง)
- Style Guide และคู่มือถูก**แคช** ไว้ คำขอหลังจากครั้งแรกจะจ่ายส่วนนี้แค่ราว 10%

## ตั้งค่าครั้งแรก
1. เข้า https://platform.claude.com แล้วสมัครหรือล็อกอิน
2. ไปที่ **Billing** แล้วเติมเครดิต (เริ่มที่ $5–$10 พอสำหรับทดลอง) แนะนำให้ตั้ง **spend limit** ไว้ด้วย
3. ไปที่ **API Keys** → **Create Key** แล้วคัดลอก key (ขึ้นต้นด้วย `sk-ant-`)
   **อย่าส่ง key ให้ใคร อย่าวางในแชต และอย่าบันทึกลงไฟล์ในโปรเจกต์**
4. ตอนนี้ติดตั้งแพ็กเกจ `anthropic` ในเครื่องแล้ว ถ้าย้ายไปเครื่องอื่นให้รัน `pip install anthropic`

## ใส่ key ทุกครั้งที่เปิด Command Prompt ใหม่
```
cd /d D:\wwm-thai-localization-enhance
set ANTHROPIC_API_KEY=sk-ant-วาง-key-ตรงนี้
```
(ค่านี้มีผลเฉพาะหน้าต่างนั้น ปิดแล้วก็หายไป)

## แปลแบบได้ผลทันที (เหมาะกับการลองหรือทำทีละน้อย)
```
python -I tools\claude_translate.py run --next 3
```
- `--next 3` = เอา 3 ก้อนถัดไปที่ยังรอแปล หรือจะระบุเลขเองก็ได้ เช่น `run 0138 0139`
- แต่ละก้อนจะแสดงจำนวนบรรทัดที่ได้และ token ที่ใช้ ตอนจบจะแสดง**ค่าใช้จ่ายโดยประมาณ**
- ลองดูก่อนว่าจะส่งอะไรโดยไม่เสียเงิน: เติม `--dry-run`

## แปลจำนวนมากแบบลดราคา 50% (Batch)
```
python -I tools\claude_translate.py batch --next 50
```
รอสักพัก (ส่วนใหญ่ไม่เกิน 1 ชั่วโมง) แล้วเก็บผล:
```
python -I tools\claude_translate.py collect
```
ถ้ายังไม่เสร็จ สคริปต์จะบอกว่ายังทำงานอยู่ ให้รัน `collect` ใหม่ภายหลัง
รายการ batch ที่ส่งไปแล้วถูกจดไว้ใน `work\queue\claude_batches.json` (ก้อนที่อยู่ใน batch จะไม่ถูกส่งซ้ำ)

## ตรวจผลและบิวด์ (เหมือนเดิม)
```
python -I tools\translate.py check 0138 0139 0140
python -I tools\translate.py review-csv --out work\review.csv 0138 0139 0140
```
จากนั้นปิดเกม แล้วดับเบิลคลิก `build_mod.bat`

## ตัวเลือก
| ตัวเลือก | ใช้ทำอะไร |
|---|---|
| `--effort medium` / `high` | ให้คิดละเอียดขึ้น ดีกับบทสนทนาหรือเนื้อเรื่อง แต่แพงขึ้น (ค่าเริ่มต้น `low` เหมาะกับ UI) |
| `--model claude-sonnet-5-5` | โมเดลที่ถูกกว่า ($2 / $10) ถ้าต้องการลดค่าใช้จ่าย |
| `--force` | แปลก้อนที่มี `.out.tsv` อยู่แล้วซ้ำ |
| `--dry-run` | ดูว่าจะส่งอะไร โดยไม่เรียก API |

## ค่าใช้จ่ายโดยประมาณ
- Opus 5.5 แบบทันที: ประมาณ **$0.05–0.10 ต่อก้อน**
- แบบ Batch: ประมาณครึ่งหนึ่ง
- ก้อนใหม่มีก้อนละ 300 บรรทัด: Opus 5.5 ประมาณ $0.5–1 ต่อก้อน (แบบทันที) หรือครึ่งหนึ่งแบบ Batch

ตัวเลขนี้เป็นการประเมิน ค่าจริงขึ้นกับความยาวของข้อความ ลองแปล 2–3 ก้อนแรกแล้วดูตัวเลขที่สคริปต์แสดง หรือดูในหน้า Usage ของ platform.claude.com ก่อนสั่งก้อนใหญ่
